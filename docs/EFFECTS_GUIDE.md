# Choose your next film effects

The scratched, faded appearance is commonly described as **aged film**, **film damage**, or a **scratched film overlay**. These are useful search terms, not claims that every editor uses identical names.

| Search phrase | Appearance | SceneForge status |
|---|---|---|
| Film scratches / scratched film overlay | Thin vertical lines and scuffs moving over the picture | Candidate |
| Dust and scratches / damaged film | Flecks, specks, scratches and missing emulsion | Candidate |
| Aged film / distressed film | Faded colors, grain, scratches and uneven exposure | Existing Old film is a partial approximation, without scratches |
| Faded film / washed-out film | Lifted blacks, subdued contrast, muted color | Faded available |
| Super 8 / 8mm film look | Coarse grain, warm color, small-frame wobble | Candidate combined preset |
| 16mm documentary film | Organic grain, subtle wear, restrained color | Candidate combined preset |
| Gate weave / film jitter | Small frame-position shifts like a projector | Candidate |
| Film flicker | Exposure varies over time | Candidate; needs restrained intensity |
| Light leaks | Colored light enters the frame edge | Candidate |
| Film burn | Warm, bright bloom sweeping across the frame | Candidate effect or transition |
| VHS tracking / analog video damage | Horizontal distortion, tracking lines and color bleed | Candidate; different from digital glitch |
| CRT scanlines | Fine horizontal lines across the image | Candidate |
| Chromatic aberration / RGB split | Color fringes at edges | Included in Glitch |
| Digital glitch / datamosh | Digital tearing or block corruption | Glitch has tearing/RGB/noise; true datamosh is not implemented |
| Vignette | Darkened frame edges | Available |
| Film grain | Fine or coarse moving texture | Available |

For a historical documentary, a restrained combination of **Faded + film scratches + dust + subtle gate weave** is a useful style to compare. Current effects select one preset per scene; an effect stack is not implemented yet. Choose the candidates you want before we add that stack.

## Transitions now available

Cut, Dissolve, Fade through black, Fade through white, Slide left/right, Wipe left/right, Circle reveal. Set these in the timeline palette for the incoming part. Use the full export to review transitions; an individual scene render has no neighbouring part.

## Motion now available

Static, Zoom in/out, Close up, Pan left/right/up/down, Diagonal rise/descend, Push & pan left, Pull & pan right. These are 2D camera transforms, not AI-generated movement or depth-aware parallax.
