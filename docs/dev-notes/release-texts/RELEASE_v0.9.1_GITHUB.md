## SceneForge Studio 0.9.1

Fixes from the 0.9.0 test and a new title style. Everything from 0.9.0 is included.

### Download
| System | File |
|---|---|
| Windows 10/11 (64-bit) | `SceneForge-Studio-0.9.1-Windows-x64-Setup.exe` |
| Linux | `.AppImage` or `.deb` |
| macOS (Apple Silicon, experimental) | `.dmg` |

On Windows, *"Windows protected your PC"* may appear. Click **More info → Run anyway**. Existing users are offered this update automatically.

### New
- **Video inside text** (Overlays tab): your title is cut out of a solid colour card, so the scene's video plays inside the letters, like a documentary "1942" title. Font, colour, opacity, size, position and outline are adjustable.

### Fixes
- Subject cutout no longer gets stuck on "Cutting out the subject…" on Windows.
- Much smaller logs, and Help → Collect diagnostics now includes recent render errors.

The full notes are in [desktop/RELEASE_NOTES.md](https://github.com/EzioDEVio/SceneForge/blob/main/desktop/RELEASE_NOTES.md).
