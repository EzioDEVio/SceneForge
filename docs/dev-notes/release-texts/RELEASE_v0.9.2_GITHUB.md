## SceneForge Studio 0.9.2

A quick fix for Video inside text. Everything from 0.9.1 is included.

### Download
| System | File |
|---|---|
| Windows 10/11 (64-bit) | `SceneForge-Studio-0.9.2-Windows-x64-Setup.exe` |
| Linux | `.AppImage` or `.deb` |
| macOS (Apple Silicon, experimental) | `.dmg` |

On Windows, *"Windows protected your PC"* may appear. Click **More info → Run anyway**. Existing users are offered this update automatically.

### Fixes
- Video inside text titles now shrink to fit the screen instead of running off the edges, and the preview shows the real size.

### New
- **Put the person or object in front of the title:** one tick box in Video inside text runs the AI subject cutout, so the subject stands in front of the colour card.

The full notes are in [desktop/RELEASE_NOTES.md](https://github.com/EzioDEVio/SceneForge/blob/main/desktop/RELEASE_NOTES.md).
