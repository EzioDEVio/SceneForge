## SceneForge Studio 0.8.0: Creator pack

Faster editing for YouTube and short-form creators. Everything from 0.7.0 and 0.7.1 is included.

### Download
| System | File |
|---|---|
| Windows 10/11 (64-bit) | `SceneForge-Studio-0.8.0-Windows-x64-Setup.exe` |
| Linux | `.AppImage` or `.deb` |
| macOS (Apple Silicon, experimental) | `.dmg` |

On Windows, *"Windows protected your PC"* may appear. Click **More info → Run anyway**. Existing users are offered this update automatically.

### What's new
- **Remove silences (jump cuts):**
  - One click finds pauses; you review them and apply.
  - Works on timeline audio, video scenes and narration.
  - Each apply is one undo step.
- **Remove filler words:** finds um, uh, hmm, "you know", "I mean" and Arabic fillers using the caption transcript. You tick the ones you want gone.
- **Auto-reframe to vertical 9:16:** File → *Create vertical 9:16 version* follows the main subject in every shot, using local AI, with a smooth camera path. The original project is untouched.
- **GPU export (NVIDIA NVENC):** much faster exports on NVIDIA graphics cards. It falls back to the CPU automatically if the GPU encode fails.
- **Live timeline playback:** press Play to watch the whole sequence from your rendered scenes, with the timeline audio and music. J, K and L control playback.
- **Keyframes:** animate stickers, overlays, textured titles and text layers (position, size, rotation, opacity), with easing.
