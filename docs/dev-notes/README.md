# Development notes

Working records from building SceneForge. Most people won't need these; they are kept for
contributors who want the history behind a decision.

- [`handoffs/`](handoffs/) — handoff notes between development sessions, the project history and
  the original technical handoff.
- [`reviews/`](reviews/) — status reports, code and stability reviews, and build validations for
  individual versions.
- [`release-texts/`](release-texts/) — the GitHub release texts for 0.7.0 to 0.9.2.
- [`evidence/`](evidence/) — screenshots, logs and JSON results that earlier reviews refer to.

The current record of changes is [`../CHANGELOG.md`](../CHANGELOG.md). Notes here describe the
state of the code at the time they were written and may be out of date.
