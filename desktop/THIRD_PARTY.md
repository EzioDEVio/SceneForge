# Desktop Alpha third-party components

This is a private, unsigned evaluation build, not a public production release.

- Electron: MIT; Chromium and third-party notices are included by Electron packaging.
- Python: PSF; dependency licenses are included where collected by the packager.
- FFmpeg 8.1.2 Windows essentials build from Gyan: GPLv3 build, separate executable. The original package README/LICENSE and download provenance accompany the binaries in resources/ffmpeg. Upstream: https://www.gyan.dev/ffmpeg/builds/ . FFmpeg source: https://ffmpeg.org/download.html .
- Noto fonts: SIL Open Font License, included under resources/app-resources/assets/fonts/OFL-LICENSE.txt.
- Synthetic typewriter sound: provenance in resources/app-resources/assets/sfx/SOURCE.md.

Public distribution gate: select the SceneForge license; complete dependency inventory, notices and corresponding-source delivery for the exact FFmpeg/dependency build; then sign installers. These references are not a claim that the public distribution review is complete. No model weights are bundled in this core alpha.
